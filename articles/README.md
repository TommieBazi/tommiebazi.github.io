# วิธีเพิ่มบทความ (สำหรับ Tommie)

1. เขียนบทความเป็นไฟล์ Markdown ตั้งชื่อเป็นภาษาอังกฤษตัวเล็กและขีดกลาง เช่น `wood-element.md` แล้วอัปโหลดไว้ในโฟลเดอร์ `articles/`
   - ย่อหน้าใหม่ = เว้นบรรทัดว่าง 1 บรรทัด
   - หัวข้อย่อย = ขึ้นต้นบรรทัดด้วย `## `
   - ตัวหนา = `**คำ**` · ลิงก์ = `[ข้อความ](https://...)` · รูป = `![คำอธิบาย](ชื่อไฟล์รูป.jpg)` (อัปโหลดรูปไว้ในโฟลเดอร์เดียวกัน)
2. เปิดไฟล์ `articles/index.json` แล้วเพิ่มรายการบทความ (คั่นด้วยเครื่องหมายจุลภาค):

```json
{
  "slug": "wood-element",
  "title": "ธาตุไม้ในปาจื้อ",
  "date": "2026-11-01",
  "excerpt": "ประโยคสรุปสั้นๆ ที่จะขึ้นในการ์ด",
  "kanji": "木",
  "cover": "wood-cover.jpg",
  "draft": false
}
```

- `slug` ต้องตรงกับชื่อไฟล์ .md (ไม่ต้องใส่ .md)
- `cover` ใส่หรือไม่ใส่ก็ได้ ถ้าไม่ใส่ การ์ดจะแสดงตัวอักษรจาก `kanji` แทน
- `draft: true` = ซ่อนไว้ก่อน ยังไม่แสดงบนเว็บ
- บทความใหม่สุด (ตาม `date`) 3 เรื่องจะขึ้นที่หน้าแรกอัตโนมัติ
